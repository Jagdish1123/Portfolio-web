A clean, fast and modern personal portfolio built with **React**, **TypeScript**, **TailwindCSS**, and **Framer Motion**.  
It highlights my work, skills, achievements and how to reach me — all wrapped in a smooth animated UI.

---

## 🚀 Live Demo  
🔗 **https://portfolio-web-green-tau.vercel.app/**

---

## ✨ Features

- ⚡ Smooth, natural animations  
- 📱 Fully responsive on all screens  
- 🎨 Gradient Hero section with animated roles  
- 🛠️ Tech stack cards with glowing icons  
- 🧩 Projects grid with hover effects  
- ✉️ Contact section with mail integration  
- 🌙 Clean dark theme UI  
- ♿ Supports reduced motion & accessible colors  


---

## ♿ Accessibility

- Semantic HTML tags  
- Keyboard-friendly navigation  
- Respects `prefers-reduced-motion`  
- High-contrast UI  
- Tap-friendly buttons on mobile
